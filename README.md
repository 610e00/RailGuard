# RailGuard AI v2.0

**智慧鐵道主動預警與旅運決策平台**

---

## 快速啟動

1. 以 VS Code 開啟 `RailGuard-AI` 資料夾
2. 對 `index.html` 按右鍵 → **Open with Live Server**
3. 瀏覽器自動開啟登入頁面

---

## 登入方式

| 方式 | 操作 |
|------|------|
| 一般登入 | 帳號：`admin` / 密碼：`1234` |
| 快速登入 | 點擊「**【王小明快速登入】**」 |

---

## 功能總覽

### 🏠 首頁
- 今日監控概況（行程數 / 預警數）
- 需要立即注意（高風險 → 預警排序）
- 我的行程摘要（依風險排序）
- 最新通知
- 快速操作：新增行程 / 查看全部 / 重置展示資料

### 🗓️ 我的行程
- 卡片式行程清單
- 依風險篩選（全部 / 高風險 / 預警 / 正常）
- 查看詳情（含 AI 建議卡片）
- 編輯 / 刪除功能
- 行程資料即時儲存至 LocalStorage

### 🔔 通知中心
- 未讀 / 已讀分類
- 點擊標記為已讀
- 一鍵全部已讀

### ➕ 新增行程
- 單次行程（日期 + 時間）
- 固定行程（星期複選 + 時間）
- 出發地 / 目的地下拉選單（真實車站）
- 備註欄位

### ⚙️ 設定
- 通知設定（推播 / 信箱 / 簡訊）
- 預警提前時間
- 重置展示資料
- 登出

## 重置展示資料

於以下任一位置點擊「**重置展示資料**」：
- 首頁 → 快速操作
- 設定頁 → 偏好設定

---

## 技術架構

- **純前端**：HTML + CSS + JavaScript（無框架）
- **資料儲存**：LocalStorage
- **部署方式**：VS Code Live Server
- **瀏覽器**：Chrome（建議）

---

## 專案結構

```
RailGuard-AI/
├── index.html              # 入口（自動跳轉）
├── pages/
│   ├── login.html          # 登入頁
│   ├── home.html           # 首頁
│   ├── trips.html          # 我的行程
│   ├── notifications.html  # 通知中心
│   ├── add-trip.html       # 新增行程
│   └── settings.html       # 設定
├── css/
│   └── main.css            # 全站樣式
├── js/
│   ├── storage.js          # 資料管理 + 工具函式
│   └── nav.js              # 共用導航
├── data/
│   ├── stations.json       # 車站資料（參考用）
│   └── defaults.json       # 預設資料（參考用）

```
